# homebrew-indice

A [Homebrew](https://brew.sh) tap for
[indice](https://github.com/edsu/indice) — a web archive server (WACZ indexing,
full-text search, and replay).

```sh
brew install edsu/indice/indice
```

`brew upgrade indice` picks up new releases. The formula is regenerated from each
release by `scripts/homebrew-formula.sh` in the main repo (see its `RELEASING.md`).
